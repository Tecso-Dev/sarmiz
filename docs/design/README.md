# طراحی

این پوشه جای wireframeها (طرح ساده‌ی چیدمان صفحه، بدون رنگ و جزئیات نهایی) و بعداً تصویر صفحه‌های نهایی سرمیز است.

[فهرست مستندات](../README.md) | [فصل ۵: فرانت‌اند](../guide/05-frontend.md) | [راهنمای برند](../brand/README.md)

## ۱. چه چیزی اینجا می‌آید

| چه | کی | چه کسی |
|---|---|---|
| wireframe صفحه‌های اصلی | هفته‌ی ۱، کار `W1-WEB-3` | زوج فرانت |
| wireframe صفحه‌هایی که بعداً اضافه می‌شوند | پیش از شروع کار همان صفحه | زوج فرانت |
| تصویر صفحه‌های نهایی، روی گوشی و تبلت | بعد از merge هر صفحه، و آخرین بار در هفته‌ی ۶ | زوج فرانت |

فایل منبع ابزار طراحی را هم، اگر داری، کنار تصویر بگذار. تصویر باید بدون آن ابزار هم دیده شود (PNG یا SVG).

## ۲. نام‌گذاری فایل‌ها

</div>

```text
<kind>-<screen>-<device>-v<N>.<ext>
wireframe-guest-menu-phone-v1.png
wireframe-kitchen-screen-tablet-v2.png
final-guest-menu-phone-v1.png
```

<div dir="rtl">

- `kind`: `wireframe` یا `final`. `device`: `phone`، `tablet` یا `desktop`.
- نسخه‌ی تازه فایل تازه است؛ نسخه‌ی قبلی را پاک نکن تا تاریخچه بماند.
- نام‌ها انگلیسی، با حروف کوچک و خط تیره.

## ۳. صفحه‌هایی که wireframe لازم دارند

- [ ] منوی مهمان (<span dir="ltr">`/t/:qrToken`</span>): دسته‌ها، کارت آیتم، جست‌وجو و فیلتر، تعویض زبان، روی گوشی
- [ ] برگه‌ی آیتم با گزینه‌ها
- [ ] سبد و ثبت سفارش
- [ ] صفحه‌ی وضعیت سفارش (<span dir="ltr">`/o/:orderId`</span>)
- [ ] ویرایشگر منو در پنل، با تب‌های زبان
- [ ] صفحه‌ی آشپزخانه (<span dir="ltr">`/panel/kitchen`</span>) روی تبلت افقی

این شش صفحه محدوده‌ی `W1-WEB-3` هستند. برای هر کدام حالت بارگذاری، خالی و خطا را هم بکش، و دست‌کم یک صفحه‌ی مهمان را در یک زبان راست‌به‌چپ و در `en` نشان بده.

## ۴. تأیید منتور

> [!IMPORTANT]
> هیچ صفحه‌ای پیش از تأیید wireframeش ساخته نمی‌شود. wireframeها با یک PR به این پوشه می‌آیند و منتور همان PR را تأیید می‌کند. اگر بعداً چیدمان یک صفحه عوض شد، wireframe تازه دوباره تأیید می‌خواهد.

در توضیح PR بنویس هر wireframe کدام قاعده‌های [راهنمای برند](../brand/README.md) و [فصل ۲۲](../guide/22-i18n-rtl-accessibility.md) را رعایت کرده است: ناحیه‌ی لمس، تضاد رنگ، و اینکه در منوی مهمان هویت کسب‌وکار جلوتر از سرمیز است.
